# v0.3.4 Release Notes

v0.3.4 publishes the public-seed browser and readiness visibility work that landed after v0.3.3.

## Highlights

- Adds the static public-seed site with searchable report, comparison, finding, and readiness pages generated entirely from committed artifacts.
- Adds sourced readiness exports: `readiness.json`, `readiness-clients.csv`, `readiness-devnets.csv`, `readiness-eips.csv`, and `readiness-sources.csv`.
- Adds structured EIP registry source metadata with retrieval dates, source dates when available, concise claims, and conservative notes.
- Strengthens client matrix, public dataset, public site, and release workflow checks.

## Readiness Caveat

Readiness exports are source visibility records. They do not infer production compatibility from devnet participation, prerelease spec work, or client-family relationships.
