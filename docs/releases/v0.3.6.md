# v0.3.6 Release Notes

v0.3.6 expands the Phase 3 readiness surfaces with public client release-note intake and stricter conservative matrix rules.

## Highlights

- Adds release-note sourced rows for Geth, Nethermind, Besu, Reth, Lighthouse, Lodestar, Prysm, Teku, Nimbus, and Grandine.
- Records release-note rows as `partial` only when the note explicitly mentions Glamsterdam, Amsterdam, Gloas, ePBS, Block Access Lists, or a tracked fork EIP.
- Keeps latest releases without an explicit readiness signal as `unknown`.
- Adds source-type counts to `readiness.json` and `site/public-seed/readiness.html` so maintainers can separate devnet image provenance, client release-note provenance, spec provenance, synthetic examples, and operator-maintained claims.
- Regenerates the public seed dataset and static site for the `0.3.6` tool version.

## Readiness Caveat

Client release-note rows are source visibility records. They do not claim complete Glamsterdam production compatibility unless the cited release note explicitly says the version is compatible or ready.
